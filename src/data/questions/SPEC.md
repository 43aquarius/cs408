# 408 真题整卷数据规范 v2（生成必读）

## 目标

把 `src/data/questions/` 下的年份文件从「抽样题」升级为**整卷**：每年 47 题 = 单项选择 40 题（每题 2 分，共 80 分）+ 综合应用 7 题（共 70 分），全卷 150 分。覆盖 2009–2026 共 18 套（408 统考始于 2009 年；「2026 年真题」指 2025 年 12 月举行的 2026 届统考）。

## 文件组织（每年两个文件）

- `src/data/questions/yNNNN-c.ts`：导出 `yNNNNc: Question[]` —— 40 道单选题（卷面题号 1–40），按题号升序
- `src/data/questions/yNNNN-a.ts`：导出 `yNNNNa: Question[]` —— 7 道综合题（卷面题号 41–47），按题号升序
- 两个新文件写完并自检通过后，**删除旧文件** `yNNNN.ts`（若存在）：`rm /home/z/my-project/src/data/questions/yNNNN.ts`
- **禁止**改动 `index.ts`、`types.ts`、任何视图组件、其他年份的文件
- 单个文件若一次 Write 写不下（参数过长报错），可拆成 `yNNNN-c1.ts`（1–20 题）/ `yNNNN-c2.ts`（21–40 题）两部分再在 `-c.ts` 中合并导出（`-a.ts` 同理）

## 卷面固定结构（硬性约束，不得违反）

| 卷面题号 | 科目 | subject | 题型 | 分值 |
|---|---|---|---|---|
| 1–11 | 数据结构 | `'ds'` | single | 每题 2 分 |
| 12–22 | 计算机组成原理 | `'co'` | single | 每题 2 分 |
| 23–32 | 操作系统 | `'os'` | single | 每题 2 分 |
| 33–40 | 计算机网络 | `'cn'` | single | 每题 2 分 |
| 41–42 | 数据结构 | `'ds'` | application | 两题合计 23 分 |
| 43–44 | 计算机组成原理 | `'co'` | application | 两题合计 23 分 |
| 45–46 | 操作系统 | `'os'` | application | 两题合计 15 分 |
| 47 | 计算机网络 | `'cn'` | application | 9 分 |

每年校验和：单选 40×2=80；综合 23+23+15+9=70；全卷 150。

## 单选题字段模板

```ts
{
  id: 'q-2010-01',        // q-{年份}-{两位题号，零填充}，与 number 一致
  year: 2010,
  number: 1,              // 卷面题号 1–40
  subject: 'ds',          // 由题号决定，见上表
  type: 'single',
  topic: '时间复杂度',      // 具体知识点，≤8 字
  difficulty: 1,          // 1 基础 / 2 中等 / 3 较难
  source: 'real',         // 原题 'real'；含图题文本化改编 'adapted'
  score: 2,
  question: '题干……？',
  options: ['…', '…', '…', '…'],  // 恰好 4 项，不含 “A.” 前缀
  answer: 'A',            // 'A'|'B'|'C'|'D'，必须与解析结论一致
  explanation: '……',      // 至少 2 句：正确项为何对 + 主要干扰项为何错
}
```

## 综合题字段模板

```ts
{
  id: 'q-2010-41',
  year: 2010,
  number: 41,             // 41–47
  subject: 'ds',
  type: 'application',
  topic: '图与遍历',
  difficulty: 3,
  source: 'real',
  score: 15,              // 该题真实分值；41+42=23、43+44=23、45+46=15、47=9
  question: '总题干……\n(1) ……（5分）\n(2) ……（10分）',
  code: { lang: 'c', text: '…' },          // 仅题目/答案需要代码时才加，可省略
  answerText: '**(1)** 结论与关键步骤……\n**(2)** ……',  // 完整参考答案，分小问
  explanation: '……',      // 解题思路 + 关键公式/性质 + 易错点
}
```

综合题**不要** `options` / `answer` 字段；单选题**不要** `answerText` / `code`（题干自带代码段的除外）。

## 内容真实性（最重要的要求）

1. **只收录 408 统考真题**。按你对当年真实试卷的记忆还原：题干、选项顺序、正确答案、各综合题分值尽量与原卷一致。
2. **严禁**：占位文本（“略”“TODO”“待补充”“此处省略”）、把习题册原创题伪装成真题、留空题号。
3. 原题含图的：用结构化文本还原（顶点/边集合、表格、ASCII 拓扑图），`source` 标 `'adapted'`，并在解析开头注明「原题带图，此处为文本化描述」。
4. **先读旧文件** `yNNNN.ts`（若存在）：其中确属该年真题的条目直接迁移复用（id/number/score 按新规范更新，内容可润色）；与你对该年真题的记忆冲突时，以真题记忆为准。
5. **保持真实选项顺序与真实答案字母**，不要打乱选项顺序（原题保真优先于答案均匀分布）。
6. 你确信是 408 真题、但不能确定属于你负责年份的题目：可用于填槽位，但必须在 worklog 中列出（id + 一句话原因），供跨年去重审校。
7. 各小问分值以「（X分）」形式写进题干，合计等于该题 `score`。

## 富文本记法（与站内渲染器一致）

- 换行 `\n`；行内代码用反引号包裹；**加粗**用双星号
- 幂写成 `2^10`、`2^-1`；十六进制带 H 后缀（如 `BF400000H`）
- 二进制串直接写（如 `1 01111110 1000…0`）
- C/伪代码放 `code` 字段（lang 用 `'c'`），不要把代码贴进 question 字符串
